# Credit Card Data Analysis Project

## 📌 Project Overview
This project analyzes customer credit card data to discover useful insights related to:
- Customer spending behavior
- Credit utilization
- Transaction patterns
- Risk analysis

The project is performed using Python libraries for Data Analysis and Visualization.

---

## 📊 Objectives
- Analyze customer transaction data
- Find spending trends
- Detect high-value customers
- Understand customer behavior
- Generate business insights

---

## 🧠 Concepts Used
- Data Cleaning
- Data Analysis
- Exploratory Data Analysis (EDA)
- Data Visualization
- Statistical Analysis

---

## ⚙️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📂 Dataset Information
The dataset contains:
- Customer details
- Credit card transactions
- Spending categories
- Payment information
